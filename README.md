# ☕ Ember & Bean Café Website

A modern, responsive café website built with **React**, **Vite**, and **Tailwind CSS**. The project showcases a premium café landing page with elegant animations, a clean user interface, and a fully responsive design.

## 🌐 Live Demo

**Website:** https://ember-brew-cafe-website-v52t.vercel.app/

## ✨ Features

- Modern and premium UI
- Fully responsive design
- Hero section
- About section
- Featured menu
- Customer testimonials
- Contact section
- Smooth animations with GSAP
- Fast performance using Vite

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- GSAP
- React Icons
- JavaScript (ES6+)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/surendra252001/ember-brew-cafe-website.git
```

### Navigate to the project

```bash
cd ember-brew-cafe-website
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
